### 1. P1 CORRECTNESS — ABA 活樹兩端相等仍可蓋混鏡射

- **位置**:`memory/agentmem/sync.py` `rebuild_local()`;0422 只覆蓋單向 A→B
  與「兩端不相等」。
- **根因**:`generation_before == generation_after` 只證明活樹兩端雜湊相同,
  不證明中間 `iter_*` 讀到的位元組屬於那個世代。A→B→A 時兩端都是 A,
  中間可以讀到 A1+B2,卻蓋上世代 A。
- **舊實作下真的紅**:`test_rebuild_does_not_certify_aba_mixed_snapshot`
  FAIL — `mixed A1+B2 stamped as generation A`。既有單向撕裂與
  never-stabilizes 兩案在舊碼下仍綠,所以這不是重複。
- **修法**:先把 `.dev-flow/` 整棵讀進記憶體,用那些位元組算
  `generation_before`,從不可變副本重建,再跟活樹比。不相等就重試,
  耗盡 `DurableMirrorDrift`。
- **測試**:`test_sync.py` +1 案。守衛 +1:
  `rebuild 蓋章用載入位元組的世代`;變異 MEM-30 把 snapshot 消費拿掉 → 紅。

### 2. P1 HEALTH CONTRACT — doctor 看不見鏡射過期

- **位置**:`memory/dev-memory.py` `cmd_doctor` → `setup.doctor()`;不走
  `_resolve()`。
- **根因**:doctor 查 schema / capability / embedding 簽章 / 路徑洩漏 /
  overlay,從不比較 `DURABLE_GENERATION_META` 與
  `sync.durable_generation()`。git pull 後鏡射過期,doctor 仍可 PASS。
- **舊實作下真的紅**:三案 FAIL,共同訊息
  `missing check durable-mirror-freshness`(stale / missing-generation /
  空專案 freshness 欄位都不存在)。doctor 沒有順便修好 —
  stale 案另外斷言世代章在 doctor 後仍對不上。
- **修法**:doctor 加非破壞性 `durable-mirror-freshness`。
  `stored == current` → ok;缺章且有內容或鏡射列、或
  `stored != current` → WARN;空專案不假紅。只在缺章時才問
  `has_mirrorable_content`,避免把 secret 測試那份故意壞掉的 YAML
  拿去 parse 讓 doctor 炸掉。
- **測試**:`test_setup_legacy.py` DoctorTest +4 案。守衛 +1;變異 MEM-31
  改檢查名 → 紅。

- **位置**:`embedding.mismatch_report()` 只呼叫 `embedding_mismatch`;
  doctor 的 `embedding-version` 只看那個數字。
- **根因**:`context` / 泛用 `_resolve()` 的 `ensure_durable_mirror` 不帶
  embedder。刷新後新 item 在 retrieval 列裡、沒有向量。既有向量簽章

  但健康訊號仍是假的。

- **修法**:`embedding_missing` / `embedding_orphaned` 與 mismatch 正交。
  `mismatch_report` 必填三個數字;`無需 re-index` 要
