# <專案名> — CONTEXT(詞彙表 / Ubiquitous Language)

> 用途:團隊 + AI 共用的業務語言。程式碼命名、文檔用詞、對話都必須用這裡的字。
> 維護:階段 1 的 grill-with-docs 逐詞條補;人工隨時可改。新人第一份讀物。
>
> 規則:
> 1. 一個概念一個詞 —— _Avoid_ 列出的同義詞禁用(code + 文檔 + 對話)。
> 2. 程式碼 identifier 必須從詞彙表取字(Contract → `Contract`,不是 `Agreement`)。
> 3. 詞條寫「系統內的精確定義」含邊界(何時算/何時不算),不是字典定義。
> 4. **只收語言,不收解法** —— 方案/手法/表設計歸屬流程文檔,不進詞彙表;
>    尚未存在於程式的概念標【提案中,尚未實作】,定案實作後才轉現在式;
>    同名異義分立詞條並互註。
>
> 收錄五類:實體 / 狀態 / 動作 / 度量(公式寫死在詞條)/ 角色。
> 不收:技術棧、架構、流程(住 docs/dev/README.md 與 docs/adr/)。

## Language

**Contract(合約)**:客戶與本公司簽署的服務協議,一筆 = contracts 表一列,以 end_date 界定效期。
_Avoid_:Agreement、協議書

**Expiring(即將到期)**:`end_date - today <= 30 天` 且尚未續約的合約狀態。改天數 = 改此詞條。
_Avoid_:快到期、將過期
