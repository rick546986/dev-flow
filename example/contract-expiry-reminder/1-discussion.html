1. 討論 — 合約到期提醒

Problem

業務靠記憶與 Excel 追合約到期,平均每季漏 2-3 件續約,客戶流失後才發現。

Context(已知事實)

  • docs/specs/contracts.md:合約 CRUD 已有,contracts.end_date 欄位存效期,無任何通知機制。
  • 後端 Go/Echo/ent,無 scheduler、無 MQ(引入 = 新 infra)。
  • 現有 dashboard 頁面有空白卡片區(前端 src/pages/Dashboard.tsx)。
  • 量級:活躍合約約 8,000 筆。

Real-world Context

Actors

Current Journey

(現況,無此功能時;訪談以「最近一次快到期的合約」實例還原)

Step 誰 真實動作 使用工具 等待誰 系統留下什麼 痛點
1 負責業務 月初翻 Excel 私表比對到期日 Excel — 無 私表更新靠自律,常漏
2 負責業務 問主管「這家要不要續」 LINE/口頭 業務主管 無 口頭交辦無紀錄
3 業務主管 要求法務先看條款 Email 轉寄合約 法務 無 法務回覆要等,進度不可見

5 負責業務 談成後改 Excel 標「已續」 Excel — 續約完成後合約資料才回系統 中間過程系統全程不可見

Workarounds

  • Excel 私表(每人一份、格式不一)追到期日;LINE 群裡喊「XX 合約快到了」。
  • 法務審閱走 Email 附件往返,版本散在信箱。
  • Step 2-4 全程沒有留下系統紀錄;負責人請假或離職,進度只能口頭重問。

Exceptions

  • 主管休假 → 代理主管口頭核,事後常忘了補知會。
  • 法務超過一週未回 → 業務電話催,或主管特批「先口頭續、條款後補」(實際做法跳過法務;正式 SOP 是先法務後簽,兩者都記)。
  • 供應商不回覆 → 擱置無提醒,直到客訴或斷約才發現。
  • 合約缺 end_date(歷史資料)→ Excel 上手填猜測值。
  • 同客戶多合約、多業務共管 → 誰跟催靠口頭認領,曾重複聯絡同一窗口。
  • 續約談到一半負責人離職 → 改派後新業務從 Email 考古,常斷線。

Evidence

  • 訪談:2 位業務 + 業務主管,各以「最近一次真的發生時怎麼處理」走完上表(2026-07-22)。
  • 實際案例:上季漏約 2 件的事後檢討(週會紀錄)。
  • 去識別化 log:某業務 Excel 私表(去客戶名)佐證 Step 1/5。
  • SOP:續約簽核辦法(正式流程=先法務後簽;與 Exceptions 記錄的實際做法並列)。
  • [Assumption] 法務平均回覆 3 天:僅主管口述印象,未取 Email 時間戳驗證。
  • [Assumption] 共管重複聯絡「約一季一次」:無記錄,僅訪談印象。

Goals

  • 業務登入後,不用翻任何清單就能看到「30 天內到期」的合約。
  • 點擊可直達該合約詳情。
  • 續約處理進行到哪(等待法務/等待主管/已聯絡供應商)有一眼可見的目前狀態與下一步,不再靠記憶與 Excel。

Non-Goals(初稿)

  • email / LINE 通知(之後再議)。
  • 自訂提醒天數。
  • 法務簽核流程系統化、自動寄信給法務/供應商(本期只記錄狀態與下一步,不做 workflow 引擎)。

驗收雛形

  • AC-1(Goal 1):任一負責業務登入 dashboard,名下 30 天內到期且未續約的合約 100% 出現在卡片。
    • 從哪看:以 <owner> 登入後的 dashboard 到期卡片。
    • 看到什麼算對:卡片列出合約 C,顯示合約名稱與剩餘天數「10 天」。
    • 拿什麼資料試:<owner> 名下合約 C,end_date = today + 10d,未續約。
  • AC-2(Goal 1):無到期合約時顯示空狀態「近期無到期合約」,不報錯。
    • 從哪看:以 <owner> 登入後的 dashboard 到期卡片。
    • 看到什麼算對:顯示「近期無到期合約」且畫面沒有錯誤。
    • 拿什麼資料試:<owner> 名下沒有 30 天內到期且未續約的合約。
  • AC-3(Goal 2):點擊卡片任一列,導向該合約詳情頁。
    • 從哪看:dashboard 到期卡片中的合約 C 那一列與瀏覽器 URL。
    • 看到什麼算對:點擊 C 後 URL 為 /contracts/C.id 並顯示該合約詳情頁。
    • 拿什麼資料試:沿用 AC-1 的合約 C,使其先出現在到期卡片。
  • AC-4(Goal 3):負責業務可將到期合約標記處理狀態(等待法務/等待主管/已聯絡供應商/不續約;「已續約」僅主管可標),卡片顯示目前狀態與下一步。
    • 從哪看:dashboard 到期卡片合約 C 那一列的狀態欄與下一步欄。
    • 看到什麼算對:標「等待法務」後,該列顯示狀態「等待法務」、下一步「等法務回覆條款」與最後動作時間。
    • 拿什麼資料試:AC-1 的合約 C,由 <owner> 將狀態標為「等待法務」。
  • AC-5(Goal 3):開啟/看過卡片不改變處理狀態;狀態僅由明確標記動作改變。
    • 從哪看:合約 C 那一列的狀態欄。
    • 看到什麼算對:<owner> 開啟 dashboard 看過卡片兩次後,C 狀態仍為「未處理」,無任何自動變更。
    • 拿什麼資料試:AC-1 的合約 C,開 dashboard 兩次、不做標記動作。
